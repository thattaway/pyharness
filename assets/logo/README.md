# pyharness logo

The mark is an ouroboros: a snake about to catch its own tail. It stands for
the self-improving loop at the heart of pyharness (each session can refine the
harness for the next), and nods to Python.

| File | Use on |
| --- | --- |
| `pyharness-mark-light.svg` / `.png` | light backgrounds (dark ink) |
| `pyharness-mark-dark.svg` / `.png` | dark backgrounds (light ink) |

Colours: ink `#1b2430` (light) or `#e9edf2` (dark), with a brass eye `#c08f22`
(light) or `#e0b54a` (dark). The PNGs are 512 × 512 with a transparent
background.

The terminal start screen shows the same mark drawn in braille dots
(`BRAND_LOGO` in `crates/ph-tui/src/chrome.rs`).
